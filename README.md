# ECG Axis & Pathology Trainer (AI-Cardiology)

Интерактивный тренажёр для изучения определения электрической оси сердца (ЭОС), нарушений ритма и проводимости, гипертрофии отделов сердца и коронарной недостаточности на 12-канальной ЭКГ. Доступен на русском, английском, немецком и испанском языках, а также в сборках для Desktop (Electron) и Android (Vite + Capacitor).
